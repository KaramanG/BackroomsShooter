# Дипломный проект BackroomsShooter
Проект выполнил студент группы БСБО-09-22 Караман Габриель Юльевич

Методы управления персонажем:
- WASD для передвижения
- LeftShift для рывка
- R для перезарядки
- MouseLeftClick для выстрела

Файлы сохранения хранятся по пути: `C:\Users\{USER_NAME}\AppData\LocalLow\BackroomsShooter\BackroomsShooter\save.json`

Модельки персонажа и мобов взяты с [Mixamo](https://www.mixamo.com). В репозитории сами модельки отсутствуют из-за веса (больше 100 Мб).

Фоновая музыка взята с игры OTXO:
- [ссылка на страницу Steam](https://store.steampowered.com/app/1608640/OTXO/)
- [альбом на Bandicamp](https://lateralis.bandcamp.com/album/otxo-original-soundtrack)
